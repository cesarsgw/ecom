# Mémo boutique MAISON

Site statique prêt (index.html, style.css, app.js, products.js).

## Reprendre
1. Modifier produits dans `products.js` (nom, prix, image, desc).
2. Remplacer avis / "2 000 clients" / nom MAISON par du vrai.
3. Brancher paiement (bouton Commander) : Stripe Payment Links ou Shopify.
4. Mettre en ligne : Netlify (glisser le dossier) ou GitHub Pages.
5. Ajouter mentions légales + CGV + contact (obligatoire en vente).
